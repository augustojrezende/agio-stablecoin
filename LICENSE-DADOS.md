**Por que não comercial.** As séries são calculadas a partir de preços públicos da Binance. Os termos de uso do Binance Vision pedem que dados derivados dos seus conjuntos de dados sejam redistribuídos com atribuição e sob CC BY-NC-SA 4.0. O projeto usa a API pública de mercado (`data-api.binance.vision`); por prudência, segue a mesma licença. Até 10/11/2026 os dados estavam sob CC BY 4.0 (registro em `docs/decisoes.md`).

Os dados de origem (PTAX e Selic do Banco Central do Brasil; preços das corretoras Binance e Mercado Bitcoin) permanecem sujeitos aos termos de uso de cada fonte. Os arquivos em `dados/bruto/` reproduzem as respostas dessas fontes e não são cobertos por esta licença.

O código-fonte do projeto é licenciado separadamente sob a licença MIT (arquivo `LICENSE`).
