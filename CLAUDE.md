# Instruções para o Claude

## Commits

Todo commit neste repositório usa:

- **Autor:** `Augusto Rezende <augustojrezende@gmail.com>`
- **Trailer na mensagem:** `Co-Authored-By: Augusto Rezende <augustojrezende@gmail.com>`

Se o autor configurado for outro, use `git -c user.name="Augusto Rezende" -c user.email="augustojrezende@gmail.com" commit ...`.

## Congelamento

Os arquivos listados em `docs/congelamento.md` (com SHA-256) não mudam até a decisão de 2028, exceto para corrigir erros registrados em `docs/decisoes.md`. Mudanças de documentação vão por branch e PR; o pesquisador faz o merge.
